# Preguntas frecuentes

## ¿El flasheo borra Ubuntu?

No. El comando usado actualiza únicamente la partición `DTB`.

## ¿Puedo usar otra versión de JetPack?

El proyecto fue validado con JetPack 4.6.6 y L4T R32.7.6. Otras versiones deben probarse antes de usarse.

## ¿Debo editar el DTS manualmente?

No. La herramienta modifica el nodo automáticamente.

## ¿Puedo ejecutar el proceso completo con un comando?

Sí:

```bash
./waveshare-tool.sh all
```
