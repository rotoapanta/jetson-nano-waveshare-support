# Instalación

```bash
git clone https://github.com/rotoapanta/jetson-nano-waveshare-support.git
cd jetson-nano-waveshare-support
chmod +x waveshare-tool.sh lib/*.sh tests/*.sh
./waveshare-tool.sh
```

Dependencias:

```bash
sudo apt update
sudo apt install device-tree-compiler usbutils python3
```
